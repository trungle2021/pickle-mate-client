# Product Overview

Pickle Mate is a pickleball match management application that helps organize players, create balanced teams, and track skill points across gaming sessions.

## Core Features
- Player management with skill point tracking
- Match generation with multiple formats (round robin, random, balanced)
- Session management for organizing tournaments
- Real-time skill point adjustments based on match results
- Dark/light theme support

## Target Users
Pickleball enthusiasts, tournament organizers, and recreational players who want to create fair and balanced matches based on player skill levels.

## Key Value Proposition
Automated team balancing and skill tracking to ensure competitive and enjoyable matches for players of all levels.
